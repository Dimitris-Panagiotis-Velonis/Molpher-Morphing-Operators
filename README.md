# Molpher-Morphing-Operators

Το repository περιέχει τα Jupyter Notebooks στα οποία υλοποιούνται και ελέγχονται οι morphing operators που αναπτύχθηκαν στο πλαίσιο της παρούσας εργασίας:

**«Υπολογιστική μελέτη επανασχεδιασμού χημικής σύστασης μορίων με κατευθυνόμενη αναζήτηση»**

Η υλοποίηση βασίζεται στις βιβλιοθήκες **Molpher** και **RDKit** και αφορά την ανάπτυξη και εφαρμογή morphing operators για την υπολογιστική τροποποίηση μοριακών δομών.

## Τεχνολογίες

* Python
* RDKit
* Molpher
* Jupyter Notebook

## Σκοπός

Σκοπός της υλοποίησης είναι η υπολογιστική προσομοίωση επιλεγμένων χημικών μετασχηματισμών και η ενσωμάτωσή τους σε διαδικασίες κατευθυνόμενης αναζήτησης στον χώρο των μοριακών δομών.
